# Никогда не поздно

Русскоязычный frontend-прототип благотворительного фонда. Next.js App Router, TypeScript, Tailwind CSS, React Three Fiber / Three.js. Контент основан на **проекте** благотворительной программы на 2027 год от 28.09.2026. Планы нигде не представлены как результаты.

## Запуск

Требуется Node.js 22.9+ (проверено на Node.js 24).

```sh
npm ci
npm run dev
```

Откройте адрес, указанный Next.js. Для production:

```sh
npm run build
npm start
```

Используется Webpack: Turbopack в проверочном окружении не смог открыть служебный порт. `scripts/dev.mjs` также принимает `--host`, `--port`, `--strictPort`; с `--strictPort` запускается уже собранный production frontend для управляемого предпросмотра.

## Страницы

- `/` — миссия, интерактивная Земля, четыре программы, порядок помощи, документы, участие.
- `/about` — миссия и направления, команда и управление (якорь `/about#team`), документы, контакты.
- `/programs` и четыре `/programs/[slug]` — официальные названия, аудитории, мероприятия, плановые бюджеты и условия.
- `/help` — способы участия и статус недоступности платежей через сайт.
- `/get-help` — планируемые условия и честное состояние недоступности приёма заявлений.
- `/reports` — исходный DOCX со статусом проекта и описание предусмотренной отчётности.
- `/contacts` — честное сообщение, что подтверждённые контакты ещё не опубликованы.

## Контент и источники

Единый типизированный источник программ: `src/lib/content.ts`. Из него создаются огоньки, селектор, каталог, страницы и ссылки. Исходный документ сохранён без изменений в `public/documents/program-2027-draft.docx`.

Команда: `src/components/team-section.tsx`. ФИО и назначения подтверждены Решением № 1 от 19.08.2026; полномочия описаны в уставе. Публичные тексты предоставлены владельцем фонда. Шесть карточек разделены на руководство, Совет фонда, Попечительский совет и Ревизора. PDF решения с персональными данными не публикуется. Фотографии и краткие биографии можно добавить позже.

Земля использует настоящие спутниковые текстуры NASA Blue Marble: 8192×4096 для desktop (4096×2048 на GPU без 8K) и 2048×1024 для мобильных. Облака Solar System Scope — отдельный прозрачный слой 4K/2K, атмосфера — тонкое Fresnel-свечение. Камера направлена на 47°N / 85°E с более длинной перспективой (distance 6 / FOV 20.3°): Россия в верхней центральной части поверхности. На desktop Земля выходит за правый и нижний края hero; на мобильном отображается компактно между текстом и выбором программы. `npm run assets` обновляет материалы NASA, `npm run assets:render` снимает статичный WebP с локального сервера. Источники и воспроизводимость — `docs/ASSETS.md`.

3D загружается отдельно. Canvas использует `frameloop="demand"`, DPR не выше 2 (1.5 на мобильных/слабых устройствах), без постобработки. Земля слегка покачивается, облака медленно движутся, четыре звезды парят в общей 3D-системе координат. Доступные HTML-кнопки следуют экранной проекции звёзд; кадры обновляются через refs без React state на каждом кадре. Движение останавливается при наведении, фокусе, выборе, скрытой вкладке, выходе сцены из видимой области, пользовательской паузе и reduced motion. Без WebGL, при потере контекста или ошибке загрузки остаётся статическое изображение и навигация. `/?static` явно включает fallback для проверки.

## Перед публикацией

Смотрите `docs/CONTENT_CHECKLIST.md`. Платежи и заявления не отправляются. Персональные данные не собираются, внешней аналитики нет, шрифты локальные. `robots` установлен в `noindex, nofollow` для прототипа: убрать только после готовности публичной версии. Не выдавайте эту сборку за работающий канал приёма помощи.

## Проверки

```sh
npm run typecheck
npm run build
npx playwright install chromium
npm test
```

Playwright-сценарии запускают production-сборку и проверяют основные пользовательские пути, reduced motion, отсутствие WebGL, mobile/tablet и прямые маршруты. Фактически выполненные проверки и ограничения текущего окружения — `docs/VERIFICATION.md`.
