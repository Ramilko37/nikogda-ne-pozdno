# Проверка прототипа

Дата: 2 октября 2026 года.

## Выполнено

- `npm run build`: production-сборка Next.js через Webpack завершена без ошибок; созданы все маршруты и четыре статические страницы программ.
- `npm run typecheck`: TypeScript без ошибок.
- `npx playwright test --list`: 18 сценариев успешно обнаружены. Это проверка загрузки тестов, не выполнение e2e-набора.
- Содержимое исходного DOCX и скачиваемого файла побайтово совпадает. Все четыре официальных названия сверены с XML документа, дубликатов нет.
- В исходниках отсутствуют пустые `href="#"`.
- Встроенный браузер: главная, страницы всех четырёх программ, о фонде, получение помощи, документы и контакты открываются напрямую с правильными заголовками.
- Встроенный браузер: выбор огонька открывает карточку соответствующей программы и синхронизирует кнопку списка. Escape закрывает карточку и возвращает фокус.
- Кнопка остановки переключает анимацию в неподвижное состояние и меняет подпись на «Включить анимацию».
- На мобильной ширине выбор «Стать самостоятельным» открывает правильную карточку.
- Форма поддержки: выбор «Разово», ввод 750 ₽ и подтверждение дают сообщение «Пожертвование не оформлено». Никакого платежа нет.
- Реальный fallback: в проверочном браузере WebGL недоступен; статическая Земля и HTML-взаимодействия работают.
- Проверены desktop 1363 px и iframe-окна 320, 390, 768 px. Горизонтального переполнения нет; высота областей огоньков 48–65 px.
- Полная главная визуально просмотрена. Ошибок приложения в консоли не обнаружено; сообщения расширения браузера не относятся к сайту.

## Визуальное сравнение

Концепт: `exec-474c8d05-7dfd-4ae8-a3ed-c4a35466c8ca.png`, создан в ходе разработки. Реализация просмотрена в браузере и через view_image.

1. Сохранены тёплый белый фон, небесно-голубая секция, сине-серый текст и тёплые огоньки.
2. Сохранена композиция первого экрана: миссия слева, Земля справа; на узком экране сначала текст и CTA.
3. Кириллица: Cormorant Garamond в заголовках, Manrope в интерфейсе. Мелкие подписи увеличены после первого просмотра.
4. Каталог представлен разделёнными линиями строками; нет сетки одинаковых карточек.
5. Сохранены свободные поля, двухколоночная секция миссии и тёмный финальный блок.
6. Намеренное отличие: вместо сгенерированной спутниковой Земли используется географически достоверная стилизация Natural Earth. Облака, орбитальные дуги и фоновый космос не перенесены.
7. Намеренное отличие: тексты концепта заменены формулировками, сверенными с DOCX. Добавлены требуемые статус проекта, список программ и управление анимацией.

Это сравнение направления и качества; не заявляется пиксельное совпадение с концептом.

## Не подтверждено в этом окружении

- WebGL-рендеринг, потеря уже созданного контекста и загрузка текстуры в живом GPU-браузере: текущий браузер не предоставляет WebGL.
- Фактическое переключение системной настройки reduced motion. Код использует matchMedia, подписку на изменения и CSS media query; добавлен автоматизированный сценарий для другого окружения.
- Полный e2e-набор Playwright не запускался: UI проверялся доступным встроенным браузером, отдельного Chromium в контейнере нет.
- Реальные касания, Safari/iOS, Android и screen reader. Iframe-проверка подтверждает CSS-компоновку, но не заменяет физическое устройство.
- Платёжный провайдер и отправка заявлений отсутствуют по исходным условиям; успешные операции не имитируются.
